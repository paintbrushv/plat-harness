# plat-harness package

Python control plane (`plat_harness`). Install from the **repo root**:

```bash
pip install -e ".[dev]"
plat-harness ask --metric millage_rate --millage-rate 25.31
```

See the root [README.md](../README.md) for the 60-second operator path.

Do not import a vendor agent SDK. Arithmetic is tools / engine extra, not a chat product.
